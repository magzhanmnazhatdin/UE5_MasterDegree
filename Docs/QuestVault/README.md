# Vault 07 — готовый уровень квеста

Карта: `/Game/QuestVault/Maps/L_QuestVault`.

Уровень использует Megan, её управление и существующие игровые Blueprint проекта. Новая карта назначена стартовой картой редактора и игры. Для запуска открой `Task0.uproject` и нажми Play.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | Движение |
| Мышь | Камера |
| E | Активировать панель рядом с персонажем |
| Space | Прыжок |
| Shift | Спринт |
| ПКМ | Прицеливание |

## Прохождение

1. **Access Control.** Подойди к голубой панели слева и нажми E. Подойди к первой двери: она откроется после разблокировки.
2. **Service Lift.** Зайди в центр оранжевого подъёмника. Он поднимется автоматически. Выйди вперёд на верхнюю площадку, когда полы сравняются. Если пропустил остановку, выйди с платформы внизу и зайди повторно.
3. **Broken Walkway.** Пройди зелёную полосу чекпоинта. Перепрыгни между пятью площадками; используй Shift + Space и регулируй направление в воздухе. Падение возвращает к чекпоинту.
4. **Auxiliary Power.** Встань на оранжевую панель возле консоли. Генератор включится и отключит красное защитное поле после короткой задержки.
5. **Transit Platform.** Зайди в центр оранжевой платформы над вторым разрывом. Во время поездки оставайся на ней. На дальнем конце выйди вперёд на причал. Платформа автоматически возвращается.
6. **Maintenance Archive.** После причала сверни в боковой архив. Обойди чередующиеся стеллажи до дальнего конца и прочитай File 07. Вернись тем же путём.
7. **Vault Authorization.** Поочерёдно подойди к панелям с номерами и нажми E в порядке **2 → 1 → 3**. Ошибка сбрасывает весь ввод. Правильный порядок разблокирует дверь хранилища.
8. Войди в хранилище и подойди к золотому объекту. Надпись **QUEST COMPLETE** обозначает финал.

Первое прохождение включает чтение подсказок, поиск записи и освоение препятствий. Точное время ручного прохождения нужно проверить перед записью видео; автоматическое прохождение с заранее известным маршрутом быстрее первого знакомства.

## Что изменено

- Добавлена отдельная карта `Content/QuestVault/Maps/L_QuestVault.umap`.
- Добавлены восемь небольших материалов для стен, пола, подсветки, предупреждений и финального объекта.
- Связаны девять существующих классов: BP_Button, BP_Door, BP_MovingPlatform, BP_CheckPoint, BP_DeathTrigger, BP_ConsoleSwitch, BP_PowerGenerator, BP_HazardBarrier и BP_SequencePuzzle.
- В пяти старых Blueprint исправлены проверки класса игрока с BP_ThirdPersonCharacter на BP_Megan: платформа, чекпоинт, зона возврата, консоль и барьер.
- У кнопок новой карты увеличены зоны взаимодействия; три кодовые панели стоят достаточно далеко друг от друга.
- У защитного поля на новой карте настроено блокирование прохода без запуска старого перехода между уровнями.
- В `DefaultEngine.ini` изменены только две ссылки на стартовую карту.
- Исходные три карты сохранены без переделки геометрии.

Дополнительная способность персонажа с новой анимацией не добавлялась: этот критерий исключён из согласованного сокращённого объёма.

## Проверки

- `Scripts/test_quest_vault_pie.py`: игровой тест с физикой — перемещение лифта и платформы вместе с персонажем, возврат к чекпоинту, генератор, снятие барьера, правильный и неправильный код, открытие обеих дверей. Для изолированных проверок используется постановка персонажа на нужные участки.
- `Scripts/test_quest_route.py`: непрерывное прохождение персонажем через движение, прыжки и платформы, без телепортаций. После физического подхода вызов нажатия панели производится программно; тест не эмулирует клавиатурный ввод E.
- Проверочная компиляция Blueprint и визуальный просмотр снимков уровня.
- Машиночитаемые результаты и журналы находятся в `Saved/QuestBuild`.

Итог: 19 Blueprint компилируются без ошибок и предупреждений; 23 проверки механик прошли; непрерывный маршрут без телепортаций пройден за 110,64 секунды без чтения подсказок. Подробности: `Validation.json`.

## Сборка карты заново

`Scripts/build_quest_vault.py` — воспроизводимый генератор новой карты. Запускается через Unreal Editor Python с доступным PythonScriptPlugin. Для обычного запуска игры этот плагин не нужен. Повторная сборка заменяет только содержимое созданной генератором карты; изменения этой карты вручную сначала сохрани отдельной копией.

Команда для Windows PowerShell из папки проекта:

```powershell
& 'D:/Epic Games/UE_5.7/Engine/Binaries/Win64/UnrealEditor-Cmd.exe' "$PWD/Task0.uproject" -run=pythonscript "-script=$PWD/Scripts/build_quest_vault.py" -EnablePlugins=PythonScriptPlugin -unattended -nullrhi -nosplash -nosound
```

Перед сдачей нужно самостоятельно записать короткое видео прохождения и передать проект преподавателю. Оценку определяет преподаватель.
